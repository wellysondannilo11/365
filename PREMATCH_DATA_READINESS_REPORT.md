# PREMATCH DATA READINESS — V2

## Current levels
- `FULL_QUANTITATIVE`: not globally available.
- `QUANTITATIVE_TRANSFERRED`: supported by the existing cross-competition evidence layer.
- `CONTEXTUAL_ANALYSIS`: supported by the existing prematch architecture.
- `INSUFFICIENT_DATA`: used when evidence remains inadequate.

## Newly available evidence
5,160 canonical fixtures have real Football-Data match-stat enrichment for shots and shots-on-target. The source is classified `DATE_LEVEL_ONLY`, so it is not promoted to Exact PIT.

## Value gate
No Value Bet is enabled from this enrichment alone. Exact PIT, validated OOS/walk-forward model performance, sufficient sample, data quality and leakage-free market evidence remain required.
