# COMPARAÇÃO DE MODELOS

Amostra histórica de 4.864 jogos, com divisão temporal 70/30. O modelo de transferência é uma referência de pesquisa para verificar se forma/temporada/descanso carregam informação além do sinal direto da competição.

A transferência entre competições específicas permanece `NOT_VALIDATED` porque apenas 5 clubes materializados aparecem em mais de uma competição no conjunto atual.
