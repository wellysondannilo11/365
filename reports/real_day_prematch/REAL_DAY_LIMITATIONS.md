# Limitações

- A base local possui 4.864 partidas, mas não contém observações suficientes para todos os clubes da rodada.
- Odds atuais encontradas na web não possuem timestamp PIT confiável para esta execução; portanto são `NON_PIT`/referência.
- Não há xG, shots, SOT, players, injuries, suspensions ou lineups materializados no pacote.
- O site oficial da CONMEBOL apresentou conflito de agregado para Botafogo x Cienciano em relação a múltiplas fontes atuais; o agregado foi bloqueado para uso científico.
- Os sinais experimentais são contextuais, não probabilidades produzidas pelo modelo.
