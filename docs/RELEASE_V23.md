# Release V23

V23 is the controlled transition from research infrastructure to real-market observation. It remains PAPER/SHADOW only. Start the observer only after configuring a valid provider credential and the runtime stack.

Example:

```bash
cd ml
THE_ODDS_API_KEY=... python scripts/run_v23_paper.py --mode SHADOW --poll-seconds 30
```

The command must be treated as real observation only when the provider is genuinely connected. No synthetic fixture is evidence of performance.
