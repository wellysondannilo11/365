# PAID API GAP REPORT V6

Paid acquisition was not purchased. The largest unresolved scientific gaps are timestamped historical odds/Exact PIT, broad historical player availability, and global event/lineup coverage. API-Football currently advertises a $0 free tier with 100 requests/day and endpoints including fixtures, events, lineups, players, sidelined/injuries, pre-match/in-play odds and statistics; higher plans increase request volume. StatsBomb Open Data covers selective competitions with matches/events/lineups, but commercial StatsBomb adds player/team match stats and broader licensed scope.

Recommendation: exhaust free/open data first; if purchasing, prioritize the provider that closes Exact PIT and availability gaps rather than buying more FT results.
